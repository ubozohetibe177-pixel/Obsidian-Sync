Privacy Policy

Last updated: 11 November 2026

This policy covers the website at this address and the Obsidian-Sync Google OAuth client. The OAuth client is used only by its owner, for the owner's own Google account and the owner's own notes.

This website

This website is a set of static pages hosted on GitHub Pages. It has no forms, no cookies, no analytics and no tracking, and it collects nothing. GitHub, as the host, may process technical request data (such as IP addresses) under the GitHub Privacy Statement.

Google user data accessed

The OAuth client is used by the third-party open-source Obsidian plugin GSync. With the owner's consent, GSync requests the Google Drive scope (https://www.googleapis.com/auth/drive) and uses it to list, download, upload and move to trash files in the Drive folder the owner configured, so the owner's Obsidian notes stay the same on their devices and in their Drive.

How the data is used, stored and shared

  • Notes travel directly between the owner's devices and Google's APIs (accounts.google.com, oauth2.googleapis.com, www.googleapis.com). There is no server operated for this client, and no copy of the notes is kept anywhere other than the owner's devices and the owner's Google Drive.
  • The OAuth client ID, client secret and refresh token are stored only on the owner's devices, in the GSync plugin's local settings file.
  • During sign-in, Google redirects to a static page published by the GSync developer at dg0988.github.io. According to the plugin's documentation, that page only passes the one-time sign-in code back to Obsidian on the same device, has no server-side code and stores nothing.
  • Google user data is not sold, not shared with or transferred to anyone, not used for advertising, and not used to train AI or machine-learning models.

Google API Services User Data Policy

Use and transfer of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

Notes stay in the owner's Google Drive and on the owner's devices until the owner deletes them. Access can be revoked at any time at myaccount.google.com/permissions; removing the plugin or its settings file deletes the locally stored tokens.

Changes and contact

Changes to this policy are published on this page. Questions can be raised through this website's GitHub repository issues.
